# Дополнительная лексика и фотографии

Добавлен файл `src/data/curated-vocabulary.json`: **200 новых уникальных единиц**, **400 естественных контекстных примеров с русским переводом**. Идентификаторы имеют постоянный префикс `curated-`; исходные 26 карточек не изменялись этой задачей. Исключены совпадения с исходным словарём. Примеры написаны для этого проекта, не скопированы из стороннего корпуса.

Распределение: A0 — 32, A1 — 85, A2 — 46, B1 — 19, B2 — 13, C1 — 5. 24 темы. Уровни — педагогическая разметка автора, не результат независимой сертификации CEFR. У существительных указаны род, определённая форма и множественное число, у выражений — необходимые глагольные формы. У неисчисляемых слов отмечено ограниченное употребление множественного числа. Это проверенное вручную пополнение, но не обещанная пользователем база из 6000 единиц; независимая редакторская проверка носителем румынского ещё не проведена.

## Фотографии

Добавлены **72 локальные фотографии** в `public/photos/curated/`. Формат WebP, размер не более 640 пикселей по большей стороне, вместе 2 694 644 байта. Одна фотография закреплена за одной лексической карточкой. Кандидаты визуально проверены на соответствие значению; иллюстрации, неоднозначные изображения и один файл с подозрительным названием стокового источника исключены. Фотографии не генерировались.

У каждой карточки с фотографией есть `imageSource` с названием, автором, страницей исходного файла и лицензией. Полный манифест `public/photos/attribution.json` также содержит URL оригинала, credit, сведения о преобразовании и отметку проверки. При показе фотографии нужно выводить атрибуцию и ссылки на оригинал и лицензию. Для CC BY-SA копия изображения сохраняет исходную лицензию; преобразование ограничено уменьшением и кодированием WebP, без кадрирования.

Источник — Wikimedia Commons. Кандидаты получены через `pageimages` англоязычной Википедии; сведения о каждом фактическом файле и его лицензии проверены через Commons API `imageinfo`, `iiprop=url|extmetadata`. Выбраны только CC BY, CC BY-SA и Public domain. Материалы только с GFDL не использовались.

Правила повторного использования: https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia/en
Требования к атрибуции файлов: https://attribution.wikimedia.org/attribution-signals/license.html

Манифест — источник истины по отдельным авторам, лицензиям и URL; общий факт размещения на Commons не заменяет индивидуальную проверку.

## Проверка данных

Проверено: уникальность `id` и румынских лемм; отсутствие пересечений с 26 исходными леммами; обязательные непустые поля; ровно два разных переведённых примера на новую единицу; допустимые уровни; отсутствие устаревшей румынской диакритики `ş/ţ`; существование всех 72 локальных WebP; уникальность файлов и SHA-256 изображений; наличие атрибуции и индивидуальной лицензии для каждой фотографии. Все 72 изображения открываются библиотекой Pillow.

Эта задача не проверяла физически слышимый звук, работу браузерного интерфейса, PWA или мобильные браузеры; эти проверки относятся к общей интеграции.
