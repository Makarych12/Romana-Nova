# Словарный корпус и границы проверки

`src/data/imported-vocabulary.json` — открытый **справочный корпус**, а не завершённый курс A0–C1. Переводы импортированы непосредственно из русского Викисловаря, без машинного перевода через английский. Два переведённых примера доступны далеко не для всех заголовков. У отсутствующих примеров оставлен пустой массив, текст не дополняется шаблонами ради количества.

## Словарные статьи

- Источник: [Русский Викисловарь через Kaikki](https://kaikki.org/ruwiktionary/%D0%A0%D1%83%D0%BC%D1%8B%D0%BD%D1%81%D0%BA%D0%B8%D0%B9/index.html), снимок ruwiktionary 2026-10-01, извлечение 2026-10-02.
- Лицензия: [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Тексты производных словарных статей и извлечённых примеров распространяются на этих условиях. Код проекта этой лицензией автоматически не покрывается.
- Каждая запись содержит `source.url`, ведущий к статье. Её история правок содержит авторов. `source.attribution` указывает Викисловарь, его авторов, Kaikki и Wiktextract. Сохранение и показ атрибуции обязательны при повторном распространении.
- Из исходных записей исключены имена собственные, отдельные флексии, морфемы, статьи без русского определения и явно помеченные устаревшие значения. Омонимические значения одного написания объединены в одну карточку; переводы могут описывать несколько значений.
- Идентификатор — `open-` + первые 16 hex-символов SHA-256 нормализованного заголовка. Изменение порядка сортировки не меняет ID. Старые карточки `w0`, `w1` и т. д. импортёр не изменяет.
- Румынские Unicode-строки нормализуются в NFC, `ş/ţ` заменяются на `ș/ț`.

## Примеры Tatoeba

- Источник: [OPUS Tatoeba v2023-04-12](https://object.pouta.csc.fi/OPUS-Tatoeba/v2023-04-12/moses/ro-ru.txt.zip), только непосредственно связанные пары RO–RU; переводы через третий язык не используются.
- Лицензия: [CC BY 2.0 FR](https://creativecommons.org/licenses/by/2.0/fr/), копия текста в `public/licenses/tatoeba-cc-by-2-fr.txt`.
- Пара сохраняет ID и ссылки на обе исходные фразы. Авторы извлекаются из актуальных `ron/rus_sentences_detailed.tsv.bz2` Tatoeba. Если автор не указан, используется «Tatoeba contributors» и ссылка на фразу.
- Для привязки примеров используется совпадение целого слова. Непроверенное морфологическое угадывание не используется.
- Выборочная проверка обнаружила неточные исходные переводы и опечатки. Они исключены явным `BAD_EXAMPLES` в импортёре. Примеры с очевидным старым написанием `î` внутри корня также исключаются. Корпус не прошёл полную редакторскую проверку носителем языка; `quality: reference` отражает это ограничение.
- `imported-examples.json` хранит сами прямые пары отдельно от их привязок к карточкам. Одна фраза может быть полезна для нескольких разных слов; число привязок не равно числу уникальных фраз.

## Оценочные уровни и темы

`levelEstimated: true` обязателен для всех импортированных записей. Уровни — приблизительные группы сложности по частотности румынского корпуса, **не сертифицированная разметка CEFR**. У многословного выражения учитывается самая редкая составляющая с понижением оценки за длину: частые предлоги не должны поднимать редкий научный термин на A0. Разметка уровней не означает готовность учебной программы соответствующего уровня.

Тематика определяется по категориям источника и словарным определениям с границей слова. Если надёжная тема не распознана, остаётся «Общая лексика». Такая категория предпочтительнее случайной неверной темы. Грамматические формы импортированы только когда присутствуют в источнике; отсутствие формы не скрывается вымышленным склонением.

## Воспроизведение

```sh
python scripts/import-open-vocabulary.py --cache /tmp/romana-data
```

Используется Python 3, стандартная библиотека. Исходники кешируются вне проекта. `imported-vocabulary-stats.json` содержит реальные количества, SHA-256 исходного словарного файла и описание метода ранжирования. Для полного указания авторов Tatoeba поместите в кеш также актуальный `rus_sentences_detailed.tsv.bz2` с https://downloads.tatoeba.org/exports/per_language/rus/rus_sentences_detailed.tsv.bz2.

При наличии Python-пакета `wordfreq` используется его частотность; метод записывается в статистику. Итоговые JSON-файлы зафиксированы в проекте, поэтому production-сборка не зависит от доступности внешних корпусов.
