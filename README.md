# ROMÂNA NOVA · 1.1.0

Существующее независимое PWA на React + TypeScript + Vite, Tailwind CSS, Motion и IndexedDB. Blue Neon интерфейс, старые уроки и профили сохранены. Регистрация, сервер и платные API не нужны.

## Запуск и сборка

Нужен Node.js 22.12+ с поддержкой `--experimental-strip-types` (проверено на Node.js 26).

```bash
npm ci
npm run dev
npm test
npm run build
npm run preview
```

Перед dev/build автоматически собирается публикуемый словарь из зафиксированных локальных JSON. Никакие внешние словари или TTS-сервисы при запуске и production-сборке не вызываются. `npm run audit:content` проверяет количества, уникальность, старые IDs, лицензии фото и полное файловое покрытие опубликованных аудиотекстов.

Vercel: Framework Vite, Build Command `npm run build`, Output Directory `dist`. `vercel.json` готов; секреты и переменные окружения не нужны. Новая публикация в аккаунт Vercel в этой сессии не выполнялась.

## Аудио: что изменилось

Предыдущий код один раз синхронно вызывал `getVoices()` и сразу отказывал при пустом списке. Он не обрабатывал `voiceschanged` и не имел файлового резерва. Теперь:

1. Голоса обнаруживаются при инициализации и через `voiceschanged`; выбираются только румынские, язык высказывания `ro-RO`.
2. Если румынского системного голоса нет, локальный MP3 запускается непосредственно из пользовательского нажатия. Ошибка или отсутствие старта системного голоса также включает файловый резерв. Длинные тексты используют файлы, чтобы избежать обрыва длинных браузерных высказываний.
3. 9641 локальный MP3, синтезированный румынским голосом Piper/Mihai (Romanian, Romania). Файлы покрывают все 7984 опубликованных заголовка, все 1593 привязки примеров (1479 уникальных), существующие учебные реплики, четыре полных диалога и тестовые фразы. Небольшое число файлов — дополнительные исходные формы и заменённые при редактуре тексты; они не считаются новыми карточками.
4. Общий плеер: play/pause, повтор, 0.75× / 1× / 1.25×, источник, загрузка, завершение и ошибки. В уроке плеер находится внутри доступного с клавиатуры диалога. Быстрый новый запрос отменяет старый; поздние события старого проигрывателя игнорируются.
5. При переходе раздела, смене карточки, закрытии урока или скрытии/блокировке экрана звук останавливается. После разблокировки пользователь запускает повтор вручную; скрытого автозапуска нет.
6. При запрете браузером `play()` показывается ошибка с просьбой нажать повтор. Нет подмены русским/английским голосом и нет фиктивного сообщения об успешной слышимости.

Настройки → **«Проверка и диагностика звука»**: системные ro-голоса, число MP3, выбранный источник, состояние, отдельная проверка файлового резерва и скачивание тестового MP3. Кнопка «Я слышу румынскую речь» фиксирует только ответ самого пользователя; событие `playing` не выдаётся за подтверждение слышимости.

Физически слышимый звук в среде агента проверить невозможно. Файлы прошли декодирование FFmpeg; у тестового MP3 проверены длительность и ненулевой сигнал. Это не заменяет прослушивания и проверки качества дикции на реальном устройстве. Chrome через Browser недоступен; реальная проверка Chrome/Firefox/Android/iPhone остаётся незавершённой.

Голос: [Piper/Mihai](https://huggingface.co/rhasspy/piper-voices/tree/main/ro/ro_RO/mihai/medium), model card в `public/licenses/ro_RO-mihai-MODEL_CARD.txt`. В model card указан датасет CC0; репозиторий голосов — MIT. Это синтезированная речь, не запись человека. Piper используется только как инструмент подготовки; Python, ONNX-модель и Piper не нужны в браузере или на Vercel. Запрещённые/неофициальные TTS-эндпоинты не используются.

## Словарь и тренировки

Поиск, тема, уровень, избранное, изученные, трудные, срок повторения, наличие фото и двух примеров, отдельный фильтр учебных карточек. Список показывает максимум 24 статьи за раз. Полный справочник загружается при открытии словаря и не включается в первый JS-экран.

Режимы: фото → слово, аудио → слово, RO → RU, RU → RO, сборка по буквам, написание по памяти. Можно тренировать выбранную фильтрами группу или открыть лексическую контрольную на 20 слов. Эти ответы обновляют существующие XP, ошибки, навыки и SRS; лексическая контрольная не выдаёт сертификат и не помечает курс C1 пройденным.

В разделах пути и практики есть ссылки на словарные подборки каждого уровня. A2–C1 остаются незавершёнными учебными программами. Сюжетные разветвлённые диалоги, расширенная железнодорожная программа и дни 17–30 также в разработке.

## Прогресс и совместимость

База `romana-nova`, версия 1, хранилище `profile`, ключ `progress` сохранены. Исходные IDs `w0`–`w25` не изменены. `src/data/vocabulary-ids.json` фиксирует соответствие лемм и ID для дальнейших редакций; повышение качества статьи не должно сбрасывать её повторения.

Ранние профили без `lessonActivity` получают пустое дополнительное поле, без изменения XP, избранного, пройденных уроков и расписания SRS. Импорт/экспорт JSON сохранён. При ошибке чтения автоперезапись отключается. Данные привязаны к домену/порту браузера; для переноса используйте экспорт.

SRS: верный ответ или «Помню» назначает 1, 2, 4… дня, максимум 60; ошибка возвращает слово через 10 минут и сбрасывает успешную серию. «Изученное» — минимум три последовательных успешных повторения. Ошибка и «Ещё учу» добавляют слово в трудные. Ответ в упражнении не получает дополнительные фиктивные XP за второе автоматическое действие SRS.

## PWA, загрузка и офлайн

HTTPS или localhost обязательны для service worker. PWA генерируется production-сборкой. Приложение и прежние текстовые уроки предзагружаются. Полный словарь имеет имя с хэшем содержимого и кэшируется после загрузки; фотографии и MP3 кэшируются по мере обращения. Браузер не скачивает сразу всю аудиотеку (~72 МБ фактических данных).

Кэши Workbox: словарь — до 3 версий, фото — до 300 файлов, аудио — до 1500 файлов на 90 дней. Для MP3 поддерживаются Range-запросы. Офлайн доступны ранее открытый словарь и сохранённые медиа. При отсутствии конкретного аудиофайла офлайн отображается ошибка; фото имеет текстовую заглушку. Хранилище может очищаться самим браузером при нехватке места; ручная установка и реальный авиарежим требуют проверки на устройстве.

## Воспроизводимость контента и аудио

```bash
npm run prepare:content
node --experimental-strip-types scripts/collect-audio-texts.mjs
# Отдельное окружение Python 3.12 с piper-tts и ffmpeg:
python scripts/generate-audio.py --model /path/to/ro_RO-mihai-medium.onnx --workers 5
npm run audit:content
npm run build
```

`generate-audio.py` использует соседний JSON-конфиг модели, переиспользует готовые файлы по хэшу текста и атомарно обновляет манифест. Список текстов — `/tmp/romana-tts/texts.json`; сборка создаёт каталог автоматически. Файлы уже зафиксированы локально, повторная генерация для обычного запуска не нужна.

Тесты, границы проверки и HTTP-проверка production-сборки описаны в `VERIFICATION.md`.
