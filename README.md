# ROMÂNA NOVA · 1.1.0

Существующее независимое PWA на React + TypeScript + Vite, Tailwind CSS, Motion и IndexedDB. Blue Neon интерфейс, старые уроки и профили сохранены. Регистрация, сервер и платные API не нужны.

## Запуск и сборка

Нужен Node.js 22.12+ с поддержкой `--experimental-strip-types` (проверено на Node.js 26).

```bash
npm ci
npm run dev
npm test
npm run build
npm run preview
```

Перед dev/build автоматически собирается публикуемый словарь из зафиксированных локальных JSON. Production-сборка не обращается к внешним словарям или TTS. Для dev/preview поддержан необязательный локальный Piper. `npm run audit:content` проверяет количества, уникальность, старые IDs, лицензии фото и полное файловое покрытие опубликованных аудиотекстов.

Vercel: Framework Vite, Build Command `npm run build`, Output Directory `dist`. `vercel.json` готов; секреты и переменные окружения не нужны. Рабочий адрес: https://romana-nova.vercel.app .

## Единая аудиосистема

Архитектура адаптирована из `BG-Learning/src/speech.ts`: готовый румынский MP3 → локальный/отдельно размещённый Piper/Mihai → настоящий голос ro-RO → явная ошибка. Все кнопки озвучки используют единый `AudioService`; один connected HTMLAudioElement живёт вне React root. Очереди диалогов ждут `ended`; отмена старой сессии не останавливает новую. Есть пауза, повтор, скорость и громкость. Для скорости системного TTS требуется повтор.

11 455 существующих MP3 покрывают 7984 слова, 2655 примеров и опубликованные уроки/диалоги. Полный индекс не импортируется в JS: 256 частей, максимум 8067 байт; в памяти — до 8 частей. Румынские диакритические знаки не удаляются. Основной JS после переноса — около 453 КБ.

Готовые MP3 работают на статическом Vercel без Python. В dev/preview Vite может запустить уже установленный Piper через параметры `.env.local` (образец: `.env.example`). В рабочем каталоге существующие окружение и модель уже подключены. Для генерации новых фраз на размещённом сайте нужен отдельный румынский endpoint с `VITE_ROMANA_TTS_ENDPOINT`; Python на статическом хостинге не запускается. `/api/tts/health` должен подтвердить ro-RO и Piper/Mihai.

Настройки → «Проверка и диагностика звука» → «Проверка воспроизведения»: кнопка запускает 20 карточек, 10 предложений и 3 диалога. Скачать отчёт можно после проверки. В нём реальные события браузера, currentTime/duration и HTTP. Физическая слышимость требует проверки на устройстве; агент не выполнял браузерную проверку, потому что Browser недоступен.

[Перенос, исходники образца и проверенные результаты](docs/AUDIO-PORT-2026-10-18.md).

## Словарь и тренировки

Поиск, тема, уровень, избранное, изученные, трудные, срок повторения, наличие фото и двух примеров, отдельный фильтр учебных карточек. Список показывает максимум 24 статьи за раз. Полный справочник загружается при открытии словаря и не включается в первый JS-экран.

Режимы: фото → слово, аудио → слово, RO → RU, RU → RO, сборка по буквам, написание по памяти. Можно тренировать выбранную фильтрами группу или открыть лексическую контрольную на 20 слов. Эти ответы обновляют существующие XP, ошибки, навыки и SRS; лексическая контрольная не выдаёт сертификат и не помечает курс C1 пройденным.

В разделах пути и практики есть ссылки на словарные подборки каждого уровня. A2–C1 остаются незавершёнными учебными программами. Сюжетные разветвлённые диалоги, расширенная железнодорожная программа и дни 17–30 также в разработке.

## Прогресс и совместимость

База `romana-nova`, версия 1, хранилище `profile`, ключ `progress` сохранены. Исходные IDs `w0`–`w25` не изменены. `src/data/vocabulary-ids.json` фиксирует соответствие лемм и ID для дальнейших редакций; повышение качества статьи не должно сбрасывать её повторения.

Ранние профили без `lessonActivity` получают пустое дополнительное поле, без изменения XP, избранного, пройденных уроков и расписания SRS. Импорт/экспорт JSON сохранён. При ошибке чтения автоперезапись отключается. Данные привязаны к домену/порту браузера; для переноса используйте экспорт.

SRS: верный ответ или «Помню» назначает 1, 2, 4… дня, максимум 60; ошибка возвращает слово через 10 минут и сбрасывает успешную серию. «Изученное» — минимум три последовательных успешных повторения. Ошибка и «Ещё учу» добавляют слово в трудные. Ответ в упражнении не получает дополнительные фиктивные XP за второе автоматическое действие SRS.

## PWA, загрузка и офлайн

HTTPS или localhost обязательны для service worker. PWA генерируется production-сборкой. Приложение и прежние текстовые уроки предзагружаются. Полный словарь имеет имя с хэшем содержимого и кэшируется после загрузки; фотографии и MP3 кэшируются по мере обращения. Браузер не скачивает всю аудиотеку или весь индекс сразу.

Кэши Workbox: словарь — до 3 версий, фото — до 300 файлов, аудио — до 1500 файлов на 90 дней. Для MP3 поддерживаются Range-запросы. Офлайн доступны ранее открытый словарь и сохранённые медиа. При отсутствии конкретного аудиофайла офлайн отображается ошибка; фото имеет текстовую заглушку. Хранилище может очищаться самим браузером при нехватке места; ручная установка и реальный авиарежим требуют проверки на устройстве.

## Воспроизводимость контента и аудио

```bash
npm run prepare:content
node --experimental-strip-types scripts/collect-audio-texts.mjs
# Отдельное окружение Python 3.12 с piper-tts и ffmpeg:
python scripts/generate-audio.py --model /path/to/ro_RO-mihai-medium.onnx --workers 5
npm run audit:content
npm run build
```

`generate-audio.py` использует соседний JSON-конфиг модели, переиспользует готовые файлы по хэшу текста и атомарно обновляет манифест. Список текстов — `/tmp/romana-tts/texts.json`; сборка создаёт каталог автоматически. Файлы уже зафиксированы локально, повторная генерация для обычного запуска не нужна.

Тесты, границы проверки и HTTP-проверка production-сборки описаны в `VERIFICATION.md`.
